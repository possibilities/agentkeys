# 0008 — Orca is no longer an inventory layer

Orca has been retired from this machine's agent environment, so AgentKeys no
longer parses its settings, vendors its defaults, or includes it in hosting
paths and reports. The earlier Orca decisions remain as historical context;
the active inventory now follows Karabiner → skhd → Ghostty, optionally through
tmux or herdr, to Neovim.
